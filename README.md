# Vilma M. Quillano — Personal Portfolio

A responsive personal portfolio website for Vilma M. Quillano, a Bachelor of Science in Information Technology student at Kabankalan Catholic College.

## Structure

- `index.html` — main portfolio page
- `styles/style.css` — lavender-and-black styling and responsive layout
- `assets/profile.png` — supplied profile image
- `public/manus-routes.json` — Webdev route manifest

## Local preview

From this folder, run:

```bash
python3 -m http.server 3000 --bind 0.0.0.0
```

Then open the local preview in a browser.
